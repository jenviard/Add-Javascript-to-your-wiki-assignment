To make the photo actually zoom/enlarge over the grid (not stretch the grid), you should use CSS transform scaling, which grows the image visually but doesn’t affect the grid layout.

#photo {

  height: auto;

  cursor: pointer;

.enlarged {

  z-index: 10;               /* put it above other grid items */
  position: relative;        /* needed for z-index to work */
